# DutchPass

Low-cost Dutch learning web app: Next.js + Supabase + browser TTS + on-demand AI.

## Local
1. npm install
2. Copy .env.example to .env.local and add Supabase values
3. npm run dev

## V1
- Learning path
- Daily practice
- Browser Dutch TTS (no TTS API cost)
- Supabase-ready data model
- AI Tutor placeholder

Next: Supabase Auth + RLS + real course data + on-demand AI Tutor + Cloudflare deployment.
